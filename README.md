
Building a Cat and Dog classifier using html (frontend) and python flask (backend)  
### Project Description
This project is a cats and dogs classifier webpage created using HTML and Python as part of the AppDev Lab assignment. It can predict from the picture uploaded if it is a cat or a dog
- HTML5
- Flask
- Visual Studio Code
- GitHub
### Files Included
- index.html - Webpage structure and layout
- train_models.py – Training different models for prediction
- app.py – Backend code
